Laboratório de Memory Leak

Abra o DevTools (F12) → Memory. Tire snapshots antes e depois de cada cenário.

1. Cenário vulnerável

Cria closures com arrays grandes, timers e listeners que não são removidos.

Nenhum ciclo executado.

2. Cenário corrigido

Remove listeners e timers e libera as referências aos arrays.

Nenhum ciclo executado.

3. Elementos de teste

Console

Abra a aba Console para observar contadores. Não use console.log(array), pois o próprio Console pode manter referências aos objetos.
